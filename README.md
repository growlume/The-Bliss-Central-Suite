# The Bliss Central Suites

Static website for GitHub Pages: `index.html`, `404.html` and the `photo-*.webp` images. Keep all files in the same folder.

## Publish
1. Create a new public repository on GitHub.
2. Upload every file from this folder to the repository root (including `.nojekyll`).
3. Go to **Settings > Pages**, set **Source** to *Deploy from a branch*, pick **main** and **/ (root)**, then Save.
4. After about a minute the site is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.

## Edit
- Replace a photo by uploading a new file with the same name.
- Prices: search `index.html` for `PRICE`. Email: search for `info@yourhotel.pk`.
- Phone and WhatsApp number: search for `923365155444`.
